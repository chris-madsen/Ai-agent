Т.е. проблема не в лимитах — а в том, что `subprocess.run()` с `timeout=30` в server.py игнорирует дочерние `sudo` процессы которые сами запускают долгие команды. Также вижу что uvicorn запускается с одним воркером — при длинных командах блокирует весь event loop. Надо добавить `workers=4`.
